# 手机配置教程（Hermes 后端版）

本教程适用于**已安装本项目 Hermes 版固件**的 ESP-Mosaico 裸机。设备侧的配置只有两步：选 Wi-Fi、填 Hermes 网关的设备通道地址，保存即重启；随后在 Hermes 主机上**批准一次配对**即可长期使用。**不需要手机 App，不需要在设备上填任何账号密码或模型 Key。**尚未安装固件请先看 [项目首页的安装步骤](../README.md#直接安装)。

**操作顺序：连接设备热点 → 打开 192.168.4.1 → 扫描并选择 Wi-Fi、填密码 → 填 Hermes 设备通道地址 → 保存并重启 → 在主机批准配对 → 按住顶部 AI 键说话。**

## 开始前准备

- 已刷好 Hermes 版固件、电量充足的设备（不需要摄像头或扩展插件）。
- 一个可访问的 **Hermes 主机**（[hermes-agent](https://github.com/NousResearch/hermes-agent) ≥ 0.21.6）：
  1. 安装 gadget 插件：
     ```bash
     hermes plugins install https://github.com/Adolanium/hermes-gadget-sdk/tree/main/plugin --enable
     hermes gateway setup        # 选 "Hermes Gadget"，按提示启用平台并重启网关
     ```
  2. 在主机上运行 `hermes gadget info`，打印出形如 `ws://192.168.1.20:8765/gadget` 的**设备通道地址**——这就是要填进设备的唯一地址。
  3. 主机的语音链路（语音消息的 STT）由 Hermes 自己配置；设备不参与识别。
- 常用 Wi-Fi 名称和密码。扫描会同时列出 2.4 GHz 与 5 GHz 网络，请选设备长期使用时信号最好的那个。
- 一台能连 Wi-Fi 的手机，浏览器即可，不装任何 App。

**建议先在能上网的网络下确认 `hermes gadget info` 能打印地址**（说明插件已随网关启动），复制好备用，再连设备热点。设备热点只提供本地配置页，不能用来访问外网。

| 网络 | 用途 |
| --- | --- |
| `Mochi-Setup-XXXX` | 手机访问设备配置后台，无密码，仅首次或手动进入时开启 |
| 家中或办公室常用 Wi-Fi | 设备长期连接 Hermes 主机，需要该网络密码 |

## 1. 手机连接设备热点

设备首次开机、尚未保存配置时，会自动开启 **`Mochi-Setup-XXXX`** 热点（末尾两个字符因设备而异）。已经配置过的设备，用 **齿轮 → 手机配置** 重新打开热点。

打开手机 **设置 → Wi-Fi**，选择这个热点，**无需密码**。提示"不安全的网络"是因为热点没设密码，"无互联网连接"不影响本地配置；手机问是否继续使用时选择保持连接。

## 2. 浏览器打开 192.168.4.1

在 Safari 或 Chrome 的**地址栏**（不是搜索框）输入：

```text
http://192.168.4.1
```

必须是 `http://`，不要改成 `https://`。页面标题是「首次配置 / First-time setup」，右上角按钮可在 **中文 / English** 之间切换，字段名随语言变化，顺序不变。

## 3. Wi-Fi：扫描、选择、填密码

页面第一个区块是 **Wi-Fi**。点开就会自动扫描附近网络，结果出现在下拉框里，括号中是信号强度（RSSI，越接近 0 越强）。没扫到就点 **扫描** 重试，或把手机拿近一些。

在下拉里选中设备要长期使用的网络，再填 **密码（开放网络留空）**。

这一步不能跳过：设备保存前会**真的用这个密码连一次**（最长约 15 秒），连不上就提示「那个网络连不上，请确认密码后重试」，并且**不会写入任何配置**，所以不会出现"保存成功但重启后哑掉"的情况。

## 4. Hermes 服务：设备通道地址、可选令牌

第二个区块是 **Hermes 服务**。

| 页面字段 | 应填写的值 |
| --- | --- |
| Hermes 设备通道地址 / Hermes gadget URL | `hermes gadget info` 打印的地址，例如 `ws://192.168.1.20:8765/gadget`；主机启用 TLS 时是 `wss://…` |
| 访问令牌（可留空）/ Access token | 仅当主机配置了 `GADGET_ACCESS_TOKEN` 时才填，与主机保持一致 |

地址必须以 `ws://` 或 `wss://` 开头，不能含空格、`@` 或 `#`（这三者会改变 URL 的解析方式）。填写时可以先勾选 **显示密钥** 核对，保存前取消勾选即可隐藏。

**这里没有账号和密码**：设备首次连接主机时自动生成并注册自己的身份密钥（存在设备 NVS 里），授权靠下一步的配对码完成。

## 5. 保存并重启

点 **「保存并重启 / Save and restart」**，页面会显示「正在连接 Wi-Fi 并保存配置（约 15 秒）…」，成功后提示「已保存，设备正在重启。请切回常用 Wi-Fi，然后看设备屏幕上的配对码。」

约两秒后设备重启，热点随之关闭，手机断开该热点属正常现象。把手机切回常用 Wi-Fi 即可，后续不需要再打开配置页。

凭据（地址与令牌）保存在设备的 NVS 分区里（明文，未启用 NVS 加密），**不会回显**：下次进配置页需要重新完整填写，请自行保管。

## 6. 配对：在主机上批准一次

设备重启后会自动连接 Hermes 主机并完成握手，屏幕（和设置页状态行）显示**配对码**，形如：

```text
配对码 QUHDM37A 等待主机批准
```

在 **Hermes 主机**上执行任一条：

```bash
hermes gadget pair              # 等待并批准下一个出现的配对码
hermes pairing approve gadget QUHDM37A   # 直接批准指定码
```

批准后一两秒内设备屏显「Hermes 在线」，**配对长期有效**，重启、换 Wi-Fi 都不需要重新批准（除非主机执行了 `hermes pairing revoke` 或 `hermes gadget forget`）。忘了码随时去设备设置页底部看当前状态行。

## 7. 第一次对话

- 左上角状态应显示 **「Hermes 在线」**（未就绪时显示「正在连接」或「服务未就绪」，设置页状态行给出具体原因）。
- **按住顶部红色 AI 键**说话，松开即发送。音频在按住期间就**流式上传**到主机，松手后主机识别、作答。
- 回答是流式上屏的：**第一段文字一到，设备就切到阅读页**并开始排页，页脚提示「正在接收回答…」；文字收完后才开始自动翻页。
- 松开按键到回答开始之间有两个不同提示：先「正在把你的话转成文字…」（主机侧识别），再「思考中」（智能体在写回答）。
- **设备不会发声，也没有喇叭相关设置**。屏幕是唯一的输出通道；设备未声明扬声器能力，主机不会下发语音。

## 8. 长回答与阅读页

回答只显示在**阅读页**：顶部小头像 + 标题「Hermes 的回答」+ 页码，正文一块 444×300 的"纸"，20 px 字号排 **10 行 × 22 个汉字 = 每页 220 字**（拉丁字母按实际宽度排，会更密一些）。500 字的回答三页读完。轻触正文翻下一页、左右横滑也可翻页、长按回首页；自动翻页间隔在设置里调（3–15 秒）。

**回答期间再按住 AI 键 = 打断**：设备发送取消，主机停止当前轮次，屏幕回到首页等待新问题。

## 9. 设置页速查

| 设置项 | 作用 |
| --- | --- |
| 拾音 | 麦克风增益 0–30 dB，嘈杂环境调高、识别过敏调低 |
| 亮度 / 熄屏 | 屏幕亮度与自动熄屏时间（5–60 秒） |
| 语言 | 中英文界面切换 |
| 翻页间隔 | 阅读页自动翻页 3–15 秒 |
| 手机配置 / Phone setup | 重新开启配置热点，用于更换 Wi-Fi 或 Hermes 地址 |

设置页最下面一行是链路状态，形如 **「Wi-Fi 已连接 · Hermes 就绪」**，异常时给出具体原因（例如「连接中」「等待配对：配对码 XXXXXXXX」「Hermes 不可达」），排错先看这一行。

## 10. 更换 Wi-Fi 或 Hermes 地址

在设备上点 **齿轮 → 手机配置 / Phone setup**。设备会保存一个"下次开机进入配置模式"的标记并重启，重启后热点重新打开。手机连上 `http://192.168.4.1`，把 Wi-Fi 和 Hermes 地址**完整重填一遍**并保存。

- 提交新配置会同时替换 Wi-Fi 与 Hermes 地址；设备身份密钥**保持不变**，换地址不需要重新配对（只要还是同一台主机）。
- 换到另一台 Hermes 主机才需要重新走一次第 6 节的配对。

## 11. 常见问题

**左上角一直「服务未就绪」/ 设置页显示「Hermes 不可达」**：按顺序检查——设备所在 Wi-Fi 是否真能上网、Hermes 网关是否在跑（主机上 `hermes gadget info` 是否能打印地址）、地址是否带错端口或子路径。改对之后重进一次「手机配置」提交即可。

**设置页显示「等待配对」**：按第 6 节在主机批准配对码。

**提示「密钥被拒绝，请在主机执行 hermes gadget forget」**：设备 NVS 里的密钥与主机登记的不一致（例如主机清过库、或这台设备曾注册过别的密钥）。在主机执行 `hermes gadget forget hg-xxxxxxxx` 后让设备重连（可用「手机配置」触发重启），重新走配对。

**提示「访问令牌不对」**：主机设置了 `GADGET_ACCESS_TOKEN` 但设备留空或不一致。重进配置页把令牌填对。

**提示「等了 45 秒没有回答」**：主机的 STT + 模型首字合计超过了设备的首字窗口。重问一次，或检查主机语音/模型配置。

**提示「没有听到声音，请按住再说」**：按住时间太短（低于 0.25 秒会被忽略）或离麦克风太远（把「拾音」调高）。

**回答只显示了一部分**：一条回答最多上屏约 64 KiB，超出部分以「…」标记截断。让智能体少写一点，或者分段提问。
